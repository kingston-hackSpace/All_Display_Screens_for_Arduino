# Animations on a LCD Display

Before screens could show smooth graphics, computers animated using just *characters* — fixed 8×5 pixel grids, swapped quickly to create motion. That's the same trick this LCD screen can do.

Below are a few examples that explore this idea in different ways — a little walking figure, a pulsing wave, and a moving pattern. Try running them, then look at the code and play around: change the dots, change the speed, make your own shapes. There's no wrong answer here — just a small grid of dots to experiment with.
